D1. Instalar as ferramentas
  Ação necessária: instalar Docker Desktop, Azure CLI, Terraform e Git.
  Programa ou site: https://www.docker.com/products/docker-desktop/ ; https://learn.microsoft.com/cli/azure/install-azure-cli ;
                    https://developer.hashicorp.com/terraform/install ; https://git-scm.com
  Arquivo envolvido: nenhum.
  Caminho do menu ou procedimento: instaladores do Windows (Docker Desktop exige WSL 2 — o instalador oferece ativar).
  Passo a passo:
    1. Instale o Docker Desktop, reinicie o Windows se pedido e abra o Docker Desktop até aparecer "Engine running".
    2. Instale a Azure CLI (MSI).
    3. Baixe o Terraform 1.9.x (zip), extraia terraform.exe para uma pasta (ex.: C:\Ferramentas) e inclua no PATH
       (Configurações → Sistema → Sobre → Configurações avançadas → Variáveis de Ambiente → Path → Novo).
    4. Abra um PowerShell NOVO.
  Resultado esperado: docker --version, docker compose version (≥ 2.24), az --version, terraform version respondem.
  Como saber se deu certo: os quatro comandos mostram versão sem erro.

  Programa ou site: Docker Desktop + PowerShell.
  Arquivo envolvido: docker-compose.yml, .env (criar a partir de .env.example).
  Caminho do menu ou procedimento: PowerShell na raiz do repositório.
  Passo a passo:
    1. Copy-Item .env.example .env
    2. Add-Content .env "GRAFANA_ADMIN_PASSWORD=<senha forte escolhida pela equipe>"
