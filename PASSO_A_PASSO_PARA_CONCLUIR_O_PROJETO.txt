1.1 O que foi construído
  AcessaCidade é uma plataforma web (não oficial, não governamental) para registrar, triar por imagem e
  acompanhar denúncias de problemas de acessibilidade em calçadas e espaços públicos. ODS 11 (principal),
  10 e 9. Um único produto atravessa as 7 disciplinas:

  Disciplina                         Componente no produto                        Pasta
  01 Generative AI for Engineering   AcessaCidade Helper (assistente)             01-Generative-AI-Engineering\
  02 Big Data & Data Integration     Pipeline Raw→Bronze→Silver→Gold + Airflow    02-Big-Data-Architecture\
  03 BI & Startup Development        Lean Canvas, negócio, pitch, painel, Ficha   03-Business-Intelligence-Startup\
  04 Applied Computer Vision         Triagem da foto com OpenCV                   04-Applied-Computer-Vision\
  05 Robotic Process Automation      Robô UiPath que cadastra denúncias           05-Robotic-Process-Automation\
  06 Secure DevOps & Cloud           Docker, Terraform/Azure, CI/CD, observab.    06-Secure-DevOps-Cloud\ e infra\
  07 Project-Based Maker Lab         Placa acessível de ponto de ônibus c/ QR     07-Project-Based-Maker-Lab\
  (produto)                          Backend FastAPI e frontend                   app\backend\ e app\frontend\

1.2 Como as 7 disciplinas se conectam (detalhes e diagramas em docs\DIAGRAMA_INTEGRACAO.md)
  - O cidadão usa o site (frontend) → a API (backend) grava a denúncia no SQLite.
  - A foto passa pelo pacote de visão (04) → resultado e 7 imagens intermediárias ficam na denúncia.
  - O assistente (01) explica status e resultado, usando dados que a API fornece.
  - O pipeline (02) exporta as denúncias pela API, processa nas 4 camadas e publica a Gold de volta → o
    painel do site (03) mostra os indicadores analíticos.
  - O robô UiPath (05) preenche o MESMO formulário web (ids estáveis), marcando origem RPA.
  - DevOps (06) empacota tudo num container, publica na Azure e monitora com Prometheus/Grafana.
  - A placa física (07) leva um QR Code para a tela de registro do site publicado.
  Contrato técnico entre os componentes: docs\CONTRATOS_DE_INTEGRACAO.md.
