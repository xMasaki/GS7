A.1 Projeto UiPath - UiPath\AcessaCidade.RPA\
  - project.json: processo Windows, linguagem VB.NET (expressionLanguage VisualBasic), targetFramework
    "Windows", main = Main.xaml, dependências UiPath.System.Activities 23.10.0,
    UiPath.UIAutomation.Activities 23.10.0, UiPath.Excel.Activities 2.22.0 (versões de referência para
    Studio 2023.10; o Studio pode pedir para atualizar/restaurar).
  - Main.xaml: carrega configuração -> verifica planilha de entrada -> Read Range -> confere colunas ->
    garante colunas de saída -> Open Browser (Edge/Chrome conforme Config) -> For Each Row com Try/Catch
    por linha (BusinessRuleException = FALHA_NEGOCIO; Exception = FALHA_SISTEMA) -> invoca
    ProcessarDenuncia.xaml -> invoca RegistrarResultado.xaml (com Try/Catch próprio) -> log por linha
    -> resumo final com totais (sucesso, falha de negócio, falha de sistema, ignoradas).
    Idempotência: linhas com Status_Robo = SUCESSO são ignoradas.
  - Workflows\CarregarConfiguracao.xaml: lê Data\Config.xlsx, aba Settings (colunas Nome/Valor), para
    Dictionary(Of String, Object); valida chaves obrigatórias.
  - Workflows\ProcessarDenuncia.xaml: valida a linha (mesmas regras da API: logradouro 3-120, bairro
    2-80, descrição 10-1000, rótulos exatos de tipo/impacto do contrato); navega para
    {URL}/#/registrar?canal=rpa (origem=RPA); Element Exists #form-denuncia; Type Into em
    #campo-nome, #campo-logradouro, #campo-numero, #campo-bairro, #campo-cidade, #campo-referencia,
    #campo-descricao; Select Item em #campo-tipo e #campo-impacto pelo texto visível; foto opcional
    (MODO_UPLOAD_FOTO = DIALOGO: clique real em #campo-foto + Type Into no diálogo "Abrir" do Windows;
    TYPEINTO: digitar no input file; IGNORAR); Check #campo-consentimento; Click #botao-enviar; polling
    até TIMEOUT_SEGUNDOS de Get Text #protocolo-gerado (regex ^AC-\d{4}-\d{6}$) e #erro-envio; Element
    Exists #resultado-envio como confirmação; erro -> BusinessRuleException com a mensagem; sem
    resposta -> TimeoutException; Click #botao-nova-denuncia. Seletores no formato
    <webctrl id='campo-logradouro' tag='INPUT' />.
  - Workflows\RegistrarResultado.xaml: grava Status_Robo, Protocolo, Mensagem (até 500 caracteres) e
    Data_Hora_Processamento e salva a planilha de saída (Write Range) a cada linha.
  - Data\Config.xlsx (gerado por script): URL_ACESSACIDADE=http://localhost:8000,
    CAMINHO_PLANILHA_ENTRADA, CAMINHO_PLANILHA_SAIDA, PASTA_IMAGENS, TIMEOUT_SEGUNDOS=30,
    NAVEGADOR=Edge, ABA_ENTRADA=Denuncias, ABA_SAIDA=Resultado, MODO_UPLOAD_FOTO=DIALOGO.
  - .gitignore local (exclui .local, .objects, .project, .screenshots, .tmh, ~$*.xlsx).
  - Todos os XAML têm anotações (sap2010:Annotation.AnnotationText) explicando cada passo.
  - Nesta continuação: acrescentado em ProcessarDenuncia.xaml o "Element Exists - #resultado-envio
    (confirmação)" + aviso no log se a caixa não for encontrada.
